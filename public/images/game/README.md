# Prototype artwork

- `portrait.webp`: generated original artwork, 8 September 2026, based on Sean's existing `src/assets/sean-betts-profile.png` identity reference. Built-in image generation, GTA VI promotional illustration direction, London riverfront at sunset, no UI or lettering.
- `scenes.webp`: generated original 2×2 illustration atlas: building, writing, speaking, about (reading order). Built-in image generation; no UI text. CSS crops the individual scenes, while links/captions remain accessible HTML.
- `map.svg`: native vector illustration for navigation; fictional London-inspired city, not geographic mapping data.
- `sean-betts.svg` and `sean-betts-inline.svg`: fixed, merged vector wordmarks typeset in Pricedown Black v5.200 by Typodermic. Source obtained 8 September 2026 from https://www.dafont.com/pricedown.font, linked download https://dl.dafont.com/dl/?f=pricedown. The included Typodermic Desktop EULA v260817 section 2.2 allows distribution of finished static artwork without font software or reusable glyph capability. No font file or reusable glyph set is included here. Wordmarks are outlined merged paths. Font license reference: https://typodermicfonts.com/licensing/ .

Generated source PNGs stay in the local Codex image archive; these WebP assets are the optimized project copies. Product screens use existing actual repository media, separate from illustrative scenes.

UI font: Barlow Condensed Semibold from Google Fonts, distributed under SIL OFL; see `public/fonts/OFL.txt`. Source https://github.com/google/fonts/tree/main/ofl/barlowcondensed .
